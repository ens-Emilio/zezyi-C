# BGM assets

Place OGG (or MP3/WAV) files here. The game runs without them (missing files are silently skipped).

| File                | When played          |
|---------------------|----------------------|
| theme_menu.wav      | Main menu            |
| theme_marathon.wav  | Marathon mode        |
| theme_sprint.wav    | Sprint mode          |
| theme_ultra.wav     | Ultra mode           |
